# Antigravity Base Meta Kit

Bộ core meta skills, rules và agents cho Google Antigravity.

### Nội dung
- 4 base skills (skill-engineer, rule-engineer, agent-architect, workflow-engineer)
- 2 rules bảo vệ
- @meta-engineer (agent có quyền dùng full base skills)

### Cách sử dụng
1. Clone repo này.
2. Copy toàn bộ thư mục `.agents/` vào project Antigravity của bạn.
3. Mở project trong Antigravity → Agent sẽ tự nhận skills/rules/agents.

**Lưu ý quan trọng**: Không chỉnh sửa trực tiếp các file base. Dùng @meta-engineer để tạo skill/rule/agent mới.
